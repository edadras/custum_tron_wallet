# TRON Vanity Address Generator

ساخت آدرس کیف پول TRON «دلخواه» که با یک متن انتخابی شروع می‌شود — مثلاً
`TRAHTApaXi...`. ابزار میلیون‌ها کلید خصوصی تصادفی تولید می‌کند تا آدرسی پیدا
شود که با متن موردنظر شما آغاز شود. خروجی شامل **آدرس** و **کلید خصوصی** است که
می‌توانید مستقیم در **TronLink** یا **Trust Wallet** وارد (Import) کنید.

> ساخته‌شده با Node.js + worker threads و بهینه‌شده برای **CPUهای چندهسته‌ای**.
> دو ترفند سرعت دارد: (۱) به‌جای ضرب کامل روی منحنی بیضوی برای هر کلید، فقط
> نقطه‌ی مولد را به نقطه‌ی قبلی اضافه می‌کند؛ (۲) **معکوس‌گیری دسته‌ای (Montgomery
> batch inversion)** — گران‌ترین عملیات را از «هر کلید» به «یک‌بار در هر دسته»
> کاهش می‌دهد. نتیجه: حدود ۳ برابر سریع‌تر در هر هسته.

## نصب

```bash
npm install
```

## استفاده

```bash
node src/index.js --prefix RAHN
# یا
npm start -- --prefix RAHN
```

آدرس‌های TRON همیشه با حرف `T` شروع می‌شوند و **۳۴ کاراکتر** دارند. شما می‌توانید
یک **بخشِ متنیِ خوانا** (متن تبلیغاتی‌تان) را ثابت کنید و بقیه‌ی آدرس تصادفی بماند.
**نمی‌توان هر ۳۴ کاراکتر را همزمان دلخواه کرد** (آن کار غیرممکن است).

### حالت‌های تطبیق (یکی را انتخاب کنید)

| گزینه | توضیح |
|-------|-------|
| `-p, --prefix <text>`  | آدرس با متن **شروع** شود — مثل `TRAHN...` (بعد از T) |
| `-m, --contains <text>`| متن در **هرجای** آدرس باشد (برای آدرس تبلیغاتی) |
| `-s, --suffix <text>`  | آدرس با متن **تمام** شود — مثل `...8888` |

### گزینه‌های دیگر

| گزینه | توضیح |
|-------|-------|
| `-t, --threads <n>`   | تعداد ریسه‌های CPU (پیش‌فرض: همه‌ی هسته‌ها) |
| `-i, --ignore-case`   | تطبیق بدون حساسیت به بزرگ/کوچک بودن حروف (سریع‌تر) |
| `-c, --count <n>`     | بعد از پیدا کردن n آدرس متوقف شود (پیش‌فرض: ۱) |
| `-h, --help`          | نمایش راهنما |

### مثال‌ها

```bash
# اولِ آدرس
node src/index.js --prefix RAHN

# متن تبلیغاتی در هرجای آدرس، بدون حساسیت به حروف (مثلاً TPCPMuU1XjpzkiFte5...)
node src/index.js --contains ESMAEiL -i

# آخرِ آدرس
node src/index.js --suffix 8888

# پیدا کردن ۵ آدرس پشت سر هم با ۸ ریسه
node src/index.js --prefix RAH -c 5 -t 8
```

> **آدرس تبلیغاتی با متن طولانی:** کافیست `--contains` را با متن دلخواه اجرا کنید
> و رها کنید تا کار کند؛ زمان مهم نیست. ابزار یک ETA زنده نشان می‌دهد و هر وقت
> آدرس پیدا شد، آدرس و کلید خصوصی را چاپ می‌کند.

## ⚠️ نکات مهم درباره‌ی کاراکترهای مجاز (Base58)

آدرس TRON با **Base58** کد می‌شود و این کاراکترها **اصلاً وجود ندارند**:

| ممنوع | دلیل |
|-------|------|
| `0` | صفر (با حرف O اشتباه می‌شود) |
| `O` | اُ بزرگ |
| `I` | آی بزرگ |
| `l` | اِل کوچک |

به همین خاطر مثال‌های رایج مثل `RAHINO` (دارای `I` و `O`) یا `ISTANBUL`
(دارای `I`) **غیرممکن** هستند. جایگزین‌های ممکن:

- `RAHINO` → `RAHiNo` (حروف کوچک `i` و `o` مجازند)
- `ISTANBUL` → `iSTANBUL` یا `1STANBUL`
- `ESMAEIL` → `ESMAEiL` (`I` بزرگ مجاز نیست، `i` کوچک مجاز است)

> Base58 به بزرگ/کوچک بودن حروف **حساس** است. برای سرعت بیشتر از `--ignore-case`
> استفاده کنید (آن‌وقت هم `A` و هم `a` قبول می‌شوند).

## ⏱️ تخمین زمان (سختی کار)

هر کاراکتر اضافه تقریباً **۵۸ برابر** کار را سخت‌تر می‌کند. روی این ابزار با
چند هسته‌ی CPU به‌طور تقریبی:

| تعداد کاراکتر دلخواه (بعد از T) | تعداد تلاش لازم (میانگین) | زمان تقریبی |
|---|---|---|
| ۳ | ~۲۰۰ هزار | چند ثانیه |
| ۴ | ~۱۱ میلیون | چند دقیقه |
| ۵ | ~۶۵۰ میلیون | چند ساعت |
| ۶ | ~۳۸ میلیارد | چند روز |
| ۷+ | میلیاردها+ | هفته‌ها تا ماه‌ها |

(ابزار هنگام اجرا یک ETA زنده بر اساس سرعت واقعی دستگاه شما نشان می‌دهد.)

## 🚀 سرعت روی سخت‌افزارهای مختلف

| سخت‌افزار | سرعت تقریبی |
|-----------|-------------|
| هر هسته‌ی CPU | ~۲۵ هزار کلید/ثانیه |
| CPU ۸ هسته  | ~۲۰۰ هزار/ثانیه |
| CPU ۳۲ هسته | ~۸۰۰ هزار/ثانیه |
| GPU (مثل RTX 3060) | چند ده تا چند صد میلیون/ثانیه |

برای استفاده‌ی بهینه از CPU چندهسته‌ای، با `-t` تعداد ریسه‌ها را برابر تعداد
هسته‌ها (یا یکی کمتر، تا سیستم آزاد بماند) بگذارید:

```bash
node src/index.js --contains ESMAEiL -i -t 31   # روی یک CPU ۳۲ هسته‌ای
```

### GPU
این ابزارِ Node.js روی CPU اجرا می‌شود و **به‌تنهایی از GPU استفاده نمی‌کند**
(کد GPU به CUDA/OpenCL نیاز دارد که زبان و معماری جداگانه‌ای است). برای متن‌های
۶ کاراکتر به بالا، GPU عملاً تنها راه سریع است. راهنمای استفاده از GPU در فایل
[`docs/GPU.md`](docs/GPU.md) آمده است.

## 🔒 امنیت — خیلی مهم

- **کلید خصوصی = کنترل کامل پول.** هرکس آن را داشته باشد به دارایی شما دسترسی دارد.
- این ابزار را ترجیحاً روی یک کامپیوتر **آفلاین** اجرا کنید.
- کلید خصوصی را در جای امن نگه دارید؛ آن را در چت/ایمیل/اسکرین‌شات نگذارید.
- خروجی روی صفحه چاپ می‌شود و در هیچ فایلی ذخیره نمی‌شود؛ خودتان آن را امن کنید.
