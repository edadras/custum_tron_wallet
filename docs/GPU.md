# استفاده از GPU برای آدرس‌های طولانی‌تر

این پروژه یک ابزار **CPU** است (Node.js). برای متن‌های ۳ تا ۵ کاراکتری کاملاً
کافی است. اما برای ۶ کاراکتر به بالا، یک GPU می‌تواند **هزاران برابر** سریع‌تر
باشد. این سند توضیح می‌دهد چرا GPU جداست و چطور می‌توان امن از آن استفاده کرد.

## چرا کد GPU جدا از این پروژه است؟

محاسبات روی GPU باید با زبان‌های مخصوص کارت گرافیک نوشته شوند:

- **CUDA** — فقط کارت‌های **NVIDIA**
- **OpenCL** — هم **NVIDIA** و هم **AMD** و هم Intel

این کدها کامپایل و معماری کاملاً متفاوتی با JavaScript دارند و باید مستقیم روی
سخت‌افزار خودِ شما ساخته و آزمایش شوند. به همین دلیل به‌جای یک نسخه‌ی GPUی
آزمایش‌نشده (که ممکن است کلیدهای نادرست تولید کند)، روش امنِ استفاده از
ابزارهای موجود را توضیح می‌دهیم.

## ⚠️ هشدار امنیتی خیلی مهم (حتماً بخوانید)

1. **بعضی ابزارهای vanity معروف، باگ امنیتی مرگبار داشته‌اند.** مشهورترین نمونه،
   ابزار «Profanity» برای اتریوم بود که از یک مولد عدد تصادفی **ضعیف** استفاده
   می‌کرد؛ در نتیجه کلیدهای ساخته‌شده توسط آن بعداً قابل حدس زدن و **سرقت** شدند.
   میلیون‌ها دلار از همین راه دزدیده شد.

2. **قانون طلایی:** فقط از ابزارهایی استفاده کنید که:
   - متن‌باز و بازبینی‌شده باشند،
   - از یک کلید پایه‌ی **تصادفیِ امن** که خودِ شما تولید می‌کنید شروع کنند
     (نه یک عدد قابل‌پیش‌بینی).

3. **هر کلیدی که GPU پیدا کرد را قبل از استفاده، آفلاین تأیید کنید** که واقعاً
   همان آدرس را می‌سازد:

   ```bash
   node src/index.js --verify <private-key-hex>
   ```

   اگر آدرسِ چاپ‌شده با آدرس موردنظر یکی نبود، آن کلید را دور بیندازید.

4. **هرگز** کلید خصوصی یا seed را در سایت آنلاین، چت یا اسکرین‌شات نگذارید.
   ابزار GPU را روی یک سیستم آفلاین اجرا کنید.

## مسیر امنِ پیشنهادی

1. یک ابزار GPUی **متن‌باز** برای TRON پیدا کنید که از OpenCL/CUDA استفاده می‌کند
   و کدش روی GitHub قابل بازبینی است (نام‌های رایج در این حوزه از خانواده‌ی
   VanitySearch/keyhunt مشتق شده‌اند). کد و Issues آن را بخوانید و مطمئن شوید
   نگرانی امنیتیِ حل‌نشده ندارد.
2. آن را روی سیستم خودتان کامپایل کنید (معمولاً نیاز به CUDA Toolkit برای NVIDIA
   یا درایور OpenCL برای AMD دارید).
3. ابزار را با متن دلخواه و حالت موردنظر (prefix/contains/suffix) اجرا کنید.
4. کلید خروجی را با دستور `--verify` این پروژه **آفلاین تأیید کنید**.
5. تنها پس از تأیید موفق، کلید را در TronLink/Trust Wallet وارد کنید.

## اگر می‌خواهید یک نسخه‌ی GPU سفارشی بسازیم

می‌توانم یک پروژه‌ی پایه‌ی **OpenCL** (سازگار با NVIDIA و AMD) برایتان داربست‌بندی
کنم که:

- کلید پایه را با RNG امنِ سیستم تولید می‌کند (بدون باگ Profanity)،
- جستجو را روی GPU با افزایش نقطه‌ای انجام می‌دهد،
- و هر کاندیدا را قبل از نمایش، روی CPU **بازتأیید** می‌کند.

توجه: این کد باید روی سختِ‌افزار GPUِ خودِ شما کامپایل و آزمایش شود (در این محیط
GPU در دسترس نیست). اگر کارت گرافیک‌تان NVIDIA است یا AMD، بگویید تا مسیر دقیق
کامپایل را هم اضافه کنم.
